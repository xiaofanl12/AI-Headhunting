# AI 猎头助手 · 新版 Web 前端

一版重新设计的美观界面：浅色 / 深色双主题、渐变强调色、卡片化布局、微交互动效。
**完全不改原后端**——原 Gradio 界面（7860）照常可用，两个界面并存。

## 启动

```bash
# 在 ai-headhunter 项目根目录下
python web/server.py
# 打开 http://127.0.0.1:7862
```

首次启动需要 5~10 秒（会复用加载原后端模块）。

## 架构

```
web/
├── server.py          # 轻量 API 层：只把 app.py / core / graph / db 的已有函数包成 JSON 接口
├── static/
│   ├── index.html     # 单页应用骨架（内联 SVG 图标库，无外部依赖）
│   ├── styles.css     # 设计系统：CSS 变量双主题 / 卡片 / 表格 / 抽屉 / 动效
│   └── app.js         # 零依赖逻辑：hash 路由 / 渲染 / 轻量 Markdown / 报告解析 / Toast / 抽屉
└── preview.py         # Playwright 视觉验收脚本（逐页截图 + 交互断言）
```

## 页面

| 页面 | 内容 |
|---|---|
| 工作台 | 对话式招聘（打字点/气泡/Markdown 渲染）、快捷指令、右栏概览与快捷入口 |
| 人才库 | 4 张统计卡（含 sparkline）、招聘漏斗（进度动画+转化率）、来源环形图、可搜索/筛选表格、点行打开简历抽屉（脱敏手机号 + 简历全文） |
| 在招职位 | 职位卡片墙（状态徽标/技能标签/关闭操作）、右侧发布表单（公司不存在自动建档） |
| 公司库 | 背调入库、公司卡片（来源徽标/在招数/简介预览） |
| 公司分析 | 评分环形图 + 五维进度条 + 合规风险三卡（失信/经营异常/行政处罚）+ 优势/风险/画像分节卡片，历史记录可点击复跑 |
| 系统设置 | MySQL/大模型/SMTP 状态卡、脱敏配置、演示数据重置 |

## 设计细节

- **双主题**：右上角切换，跟随系统偏好，localStorage 记忆。
- **零依赖**：不引任何 CDN/框架，内网离线可用；图标是内联 SVG sprite。
- **动效**：视图切换淡入、卡片 hover 抬升、漏斗条流光、打字点、Toast 滑入、抽屉滑入。
- **安全边界**：手机号脱敏展示；批量删除 / DDL 拦截逻辑沿用后端，未做任何放宽。
